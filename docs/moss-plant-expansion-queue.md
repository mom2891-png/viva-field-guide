# 이끼·식물 누락과 기본 정보 보강 대기열

확인일: 2026-11-04. 사용자 요청: 기본 이끼와 식물 다양성을 더 넓힐 후보 발굴.

## 후속 반영 (2026-11-04)

현재574항목/식물212. 원래42검토건 중 신규 후보5건(쥐꼬리·큰솔·서리 유통형·미크로그램마2종)을 항목으로 반영하고 기존 보강2건(비단 이름·털깃털 사진/학명 별칭)을 처리했다. 여기에 국내 재배 연구로 물가양털이끼1종을 추가해 이번 신규6건이다. 비단 사진과 세줄/양털/큰초롱 정체는 보류. 나머지 기존 보강도 완료가 아니다. 아래42건 표·568항목/206식물 수치는 발굴 당시 기록이며 전체를 처리 완료로 읽지 않는다. 최신 최소 근거는 catalog-coverage의 기본 이끼 배치 참조.

## 현재 문제

현재 식물206항목 중 이끼34·우산이끼3=37항목이다. 지피8·착생란6·보석란6·브로멜리아/착생11로, 관엽49·덩굴40에 비해 구성 폭이 좁다. 이는 현재 데이터 분류별 집계이며 적정 수량/전체 종수 기준이 아니다. 특히 이끼 사진7개가 비어 있으며 비단·깃털·털깃털·봉황·그늘대호꼬리가 포함된다. 해외 이끼 몇 종이 이미 있어도 국내 기본 판매명을 찾기 어려우면 도감의 기초가 부족하게 보인다.

비단이끼는 미수록이 아니라 plant-176에 비단이끼 유통형 (준페로이데움)이라는 긴 이름·사진 없음으로 등록되어 있다. 공개 사이트와 미배포 로컬은 버전이 다르다. 대표명·별칭·종 구별·사진 보강을 우선 검토한다. 국가 목록은 Leucobryum juniperoideum의 국명을 가는흰털이끼로 기록한다. 기존 Leucobryum glaucum과 합치지 않는다.

## 처리 순서와 범위

1. 기본 이끼6판매명 신규 후보부터 정체 대조. 기존 기본 이끼8항목/판매형은 통용명·사진·관리·상품 연결을 보강한다.
2. 지피·작은 덩굴·착생 고사리·소형 초화를 늘려 모양과 식재 역할을 넓힌다. 기존 식물의 다른 포트·색상·판매 코드는 별도 종으로 늘리지 않는다.
3. 착생란·지생란과 브로멜리아를 넓힌다. 통풍·냉량·계절 변화·성숙 크기를 먼저 확인한다. 해외 판매 자료는 국내 유통/인기 근거로 쓰지 않는다.
4. 호마로메나·라비시아 추가 유통형은 기존 항목과 중복 검토한 뒤 하위 연결/독립 유통형/보류를 결정한다. 이쪽 이름만 늘려 식물 확장을 끝내지 않는다.

아래42검토건은 신규 검토30(국내 판매명/제공 메뉴18, 해외 참고12)와 기존 보강12다. 종 수나 추가 확정 수가 아니다. 학명·관리·사진·가격 검증과 실제 도감 반영은 다음 작업이며 현재568항목을 유지한다. 수량 상한 없이 후속 업체 카테고리를 대조한다.
