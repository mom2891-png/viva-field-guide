# 비바 생물도감 수록·정보 완성 계획

작성일: 2026-11-03 (Asia/Seoul)

**목표:** 국내 비바리움·테라리움 취미에서 접하는 주요 동물·식물·정화생물을 폭넓게 찾을 수 있고, 각 항목에서 정체·환경·크기·구매 정보를 구분해 확인할 수 있는 한국어 도감을 만든다.

**방식:** 분류군별 기준 목록과 국내 판매처 전체 목록을 교차 대조한다. 기존 정적 HTML/CSS/JavaScript와 JSON 구조를 유지하며 데이터 작업을 우선한다. 사진·관리·가격의 근거 수준을 각각 관리한다. 아래 단계는 각각 독립적으로 검증·커밋할 작업 묶음이며, 전체 수록량에 임의 상한을 두지 않는다.

**현재 단계 (2026-11-03):** 단계 0의 목차와 크기 필터를 구현하고 자동 검사를 통과했다. 동물 338·식물 186 항목이며, 등각류 목록 95상품 대조와 드워프화이트 추가를 진행했다. 실제 화면 최종 검수와 단계 A–G의 나머지 조사는 미완료다. 67cf20c 구현은 작업 브랜치에 업로드되었으나 main 공개 배포는 하지 않았다. 이후 작업은 사용자가 승인한 9단계 순서로 수행하고, 추가 업로드·배포는 최종 결과 보고 뒤 지시를 따른다.

**2026-11-04 후속:** 현재560항목/목차835노드. 단계0 대표 UI를1440×900/390×844에서 검수하고 구매처 탭 왕복의 history 덮어쓰기 결함을 수정했다. 플랜티멀48 목록150상품을 대조 후보28/보류122로 기록하고 신규4항목·기존4항목을 근거·한계와 함께 보강했다. 단계A–G 전수 조사/정보 심화는 진행 중이며 전체 완료가 아니다. 아래 출발점 수치는 초기 기록, 최신 입력 집계는 catalog-status를 따른다. 추가 업로드·main·배포 금지 지시 유지.

**목차 설계 보완:** 사용자가 더쥬의 다단 메뉴를 참고 화면으로 지정했다. [다단 목차·전체 보강 설계](../specs/2026-11-03-field-guide-navigation.md)를 함께 따른다. 동물 전체군의 조사와 기존 종별 정보 심화가 모두 대상이며, 정화생물 보강만으로 동물도감을 완료하지 않는다.

## 1. 수록 범위

- 핵심: 열대 습식 비바리움, 식물 중심 테라리움, 냉량형·환기형 식재, 팔루다리움 육상·수변 구역, 정화생물.
- 별도 환경으로 유지: 건조형 바이오액티브 사육, 대형 사육종, 계절 관리가 필요한 자생식물·양서류. 같은 도감에 있다고 한 환경이나 합사를 권하지 않는다.
- 동물: 게코·소형 도마뱀·기타 기존 파충류, 개구리·두꺼비·도롱뇽·뉴트, 등각류·톡토기, 노래기·게·달팽이·거미·곤충류. 주 사육동물, 정화생물, 먹이생물의 역할을 섞지 않는다.
- 식물: 정글 관엽·덩굴·지피, 브로멜리아, 소형 착생란·보석란, 고사리·석송, 이끼·우산이끼, 수변 식재와 적합한 식충식물. 작은 판매 규격을 성숙 크기나 비바리움 적합성으로 간주하지 않는다.
- 해외 전문 자료는 분류·사육·식재의 누락 후보 확인에 사용한다. 국내 취급 근거와 구분하고 구매처 모음은 국내 업체만 유지한다.
- 일반 관상어·해수생물 전체, 전체 원예식물, 모든 유전 모프를 전 세계 단위로 망라하는 작업은 이번 핵심 범위와 분리한다. 필요한 팔루다리움 수역 생물은 환경·수질 정보와 함께 후속 범위로 명시한다.

## 2. 출발점과 측정 방식

|지표|현재 확인값|의미|
|---|---:|---|

현재 명시적인 전수 대조 근거가 있는 묶음은 꿈속의 자연 식물 카테고리 28상품과 이끼상점 제공 가격표36옵션이다. 이를 다른 업체나 도감 전체의 조사 완료로 확대 해석하지 않는다.

조사 단위는 `업체 × 카테고리 × 확인일`이다. 각 단위에서 총 표시 상품 수, 방문 페이지 수, 중복 제거 상품 수와 처리 건수를 대조한다. 무한 스크롤·품절 숨김·하위 카테고리·모바일 중복도 점검한다. 접근 실패와 로그인 요구는 미조사 상태로 남긴다.

완료 지표는 다음을 따로 계산한다.

1. 조사 범위: 선정한 카테고리 중 전수 확인 완료/미확인/접근 불가 수.
2. 품목 처리: 기존 연결/신규 추가/품종·모프 연결/미확정 보존/범위 밖 제외 건수. 조사 상품마다 하나의 처리 결과가 있어야 한다.
3. 종 정체: 종명 대조/속만 확인/유통명/동정 충돌. 상품명을 찾았다는 이유로 종 동정 완료로 표시하지 않는다.
4. 정보 충실도: 사진·크기·관리·가격을 각각 확인/미조사/자료 미확인/상충으로 구분한다. 값이 없는 상태와 조사를 안 한 상태가 구분돼야 한다.
5. 잔여 후보: 분류군별 미처리 후보·이름 충돌·근거 부족 항목 수.

### 단계 B — 정화생물과 핵심 소형 생물

**우선 이유:** 전시 동물 수가 많아도 정화생물 한 축이 빠지면 실제 비바리움 구성에 필요한 검색이 끊긴다.

- [ ] 현재 등각류20·톡토기14항목을 국내 전문 업체의 전체 목록 및 전문 사육 자료와 대조한다.
- [x] 확인된 누락 사례인 드워프화이트 등각류부터 국내명·학명·판매 유통형·상품 중복 여부를 확인한다. 가격과 사진은 각각 독립적으로 검증한다.
- [ ] 청소 역할·먹이 역할·주 사육 역할과 건조/습식 선호·통풍·기질 조건을 확인한다. 같은 역할 표시를 합사 보증으로 쓰지 않는다.
- [ ] 소형 노래기·게·달팽이·점핑스파이더 등 현재 얇은 군을 순차 전수 대조한다. 판매 근거가 없는 이름을 수량 확보 목적으로 추가하지 않는다.

**수정 대상:** dist/species.json, 필요시 dist/morphs.json, scripts/validate.mjs. 새 역할·관리 필드가 필요하면 기존 UI와 검사에 작은 단위로 도입한다.

**완료 기준:** 조사 대상 업체에서 발견한 관련 품목은 전부 기존 연결·추가·미확정·제외로 처리되고, 신규 항목의 인기·동정 수준을 임의로 확정하지 않는다.

- [ ] 주요 모프·지역형·품종은 기존 종 아래에 넣고 특정 모프 사진을 일반 종 사진으로 대체하지 않는다. 형태·관리 차이가 있는 경우에만 근거를 붙인다.
- [ ] 국내 취급 여부와 현재 판매 가능 여부를 구분한다. 보호·거래 관련 정보가 필요한 항목은 실행 시점의 공식 자료와 확인일을 사용한다.

**완료 기준:** 조사군의 후보 처리 누락이 없고, 건조·대형·냉량 사육종이 일반 소형 습식 추천으로 섞이지 않는다.

### 단계 E — 기존 항목을 도감 수준으로 심화

각 배치에서 새 항목을 추가할 때 기존 항목도 함께 심화한다. 가격만 채운 항목을 관리 정보까지 완성됐다고 세지 않는다.

|영역|채울 내용|입력 규칙|
|---|---|---|
|정체|표시명·학명/이명·분류·유통명·동정 수준|이름 충돌은 보류 이유 표시, 기존 ID 유지|
|크기|성체/성숙 크기·측정 부위·범위/최대·성장 특성|판매 당시 규격과 분리, 모르는 하한 생성 금지|
|동물 관리|공간·온도·습도 주기·환기·먹이·활동·수역 등|종별 근거, 조건과 위험의 의미를 함께 설명|
|식물 관리|성숙 크기·빛·수분·배수·환기·배치·계절성·증식|밀폐 테라리움과 환기형 비바리움 적합성 구분|
|사진|일치한 분류군·전체 모습·저작자·라이선스·원본|권리·동정 불명 사진 대신 준비 중 유지|
|가격·구매|판매 단위·범위·옵션·상태·확인일·직접 상품/문의 구분|자료 없으면 확인 중, 가격으로 인기 생성 금지|

- [x] 각 필드의 최소 근거·확인일·상충 처리 기준을 docs/catalog-field-standards.md에 문서화했다. 새 관리 데이터 구조는 별도 작은 구현 계획으로 확정한 뒤 추가한다.
- [ ] 국내외 국립기관·공식 분류 DB로 이름을 대조하고 전문 사육·원예 자료로 관리 내용을 확인한다. 판매 문구만으로 생태 조건을 확정하지 않는다.
- [ ] 출처는 후속 검증 가능한 최소 URL·확인일·해당 필드 범위를 보존한다. 공개 UI에 조사 원문·출처표를 만들지 않는다. 사진 권리 표기는 유지한다.
- [ ] 사진 없는96·크기 없는360·가격 없는310항목의 미조사/조사 후 미확인 상태를 구분하고 갱신한다. 이 수치는 출발점이며 조사 확장에 따라 바뀐다.

**완료 기준:** 핵심 종은 종별 관리 설명이 있고, 자료가 없는 항목도 무엇을 확인하지 못했는지 명확하다. 정확성을 위해 남긴 공란을 추정치로 메우지 않는다.

### 단계 F — 항목 통합·검색·검증

- [ ] 별칭·옛 학명·띄어쓰기·대표 한글 음역을 검색으로 확인한다. 후보 검토에서 발견한 중복 종은 동일성 근거를 확보한 뒤 처리한다.
- [ ] 통합이 필요하면 기존 ID와 관심 목록이 끊기지 않는 연결 방식을 먼저 설계한다. ID 재번호 부여나 오래된 항목 일괄 삭제로 해결하지 않는다.
- [ ] 가격 단위·품절·이미지 크레딧·연결 없는 모프·속별 탐색·불확실한 유통명 보존 검사를 유지한다. 행동 변경은 실패하는 회귀 검사부터 추가한다.
- [ ] 실제 브라우저에서 동물·식물·구매처 왕복, 긴 이름, 상세 펼침, 사진 고정, 관련 항목/가격표 복귀를 데스크톱과390px에서 확인한다.
- [ ] 정보 조사 상태를 사용자에게 보여줄 필요가 있으면 짧은 안내·필터로 설계한다. 작성 중임을 숨기거나 긴 연구 설명을 제품 화면에 넣지 않는다.

**명령:** `npm run check`, `git diff --check`, 기존 ID·사진·인기 보존 비교. 데이터만 바꾸는 배치는 전체 데이터 검사와 변경 항목 표본 검수, UI를 바꾸는 배치는 브라우저 검수를 추가한다.

### 단계 G — 배치별 기록·반영·재조사

- [ ] 한 분류군·한 조사 묶음씩 완료하고 명시 파일만 커밋한다. 배치 크기는 검토 가능성에 맞추며 도감 상한으로 삼지 않는다.
- [ ] HANDOFF에 조사한 업체/카테고리·날짜, 후보 처리 수, 새 항목/기존 보강 수, 보류·접근 실패·검증 결과를 남긴다.
- [ ] 캐시 버전·관련 문서·화면 초기 수치를 함께 맞춘다. 다음 사람이 처리된 카테고리를 처음부터 재수집하지 않도록 기준을 남긴다.
- [ ] 공개 반영을 진행할 때 원격 main 변경을 보존하며 동기화하고 검사한다. 원격 반영과 Actions·공개 사이트 버전 확인을 로컬 완료와 별도로 보고한다.
- [ ] 마지막 조사 이후의 신규 상품·학명 변경·죽은 링크·오래된 가격을 차기 조사 대상으로 만든다. 재조사 주기는 실제 변동과 자료의 노후도를 보고 정하며 자동 실행은 별도 요청 시 설정한다.

## 4. 첫 실행 묶음

다음 실행은 전체를 동시에 벌리지 않고 아래 순서로 시작한다. 목차 UI와 콘텐츠 전수 보강은 각각 검증하고 완료 상태를 분리한다.

1. 단계0의 목차·분류 매핑과 동물/식물 종별 필수 정보 양식을 확정한다.
2. 목차 UI와 기존523항목의 도달 가능성·검색·복귀를 검증한다.
3. 단계A의 기준 장부에 모든 동물군과 식물군의 조사 대상·미처리 후보를 등록한다.
4. 등각류·톡토기, 지피·소형 덩굴·브로멜리아부터 조사하되, 이어서 게·달팽이·노래기·곤충·거미류 및 개구리·게코·그 외 파충류/양서류도 순차 전수 대조한다.
5. 새 항목과 함께 기존 항목의 종별 관리·성체/성숙 크기·사진·가격을 심화한다.
6. 검사·브라우저 검수·HANDOFF·커밋 후 분기별 남은 후보 수로 다음 묶음을 정한다.

## 5. 1차 도감판 완료 판단

‘지구상의 모든 생물 수록’이나 단순한 총 항목 수로 완료를 선언하지 않는다. 다음 조건을 만족하면 조사 범위를 명시한 1차 도감판으로 판단한다.

- 핵심 분류군별 조사 대상이 확정되고, 선정한 국내 카테고리는 전수 확인 또는 접근 불가 사유가 기록돼 있다.
- 발견 품목의 처리 결과가 빠짐없이 있으며, 흔한 핵심 후보가 미처리 상태로 남아 있지 않다. 가격표의 불명확한 이름도 검색 가능한 판매 품목 또는 미확정 항목으로 찾을 수 있다.
- 핵심 항목의 종별 관리·성체/성숙 크기·환경 제약을 확인했다. 사진·가격 확보 실패는 상태를 명시하고 정체·사육 정보의 누락과 구분한다.
- 전체 미처리 후보·동정 충돌·부족한 필드·미검수 사진을 수치와 목록으로 제시할 수 있다.
- 자동 검사·대표 실제 화면 검수·원격 반영 및 배포 확인을 통과했다.

이후에도 새 유통명·사육종·품종과 새 자료를 반영하며 범위를 확장한다.
