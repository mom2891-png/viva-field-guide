## 반영

- 동물: 대분류 → 세부군 → 속 → 종/유통항목 → 모프·패턴. 동물208속 중 반복69속을 메인에서 한 카드로 묶고 선택하면 해당 종별 카드가 나온다. 단일 검색 결과는 바로 종 카드를 연다. 식물111속 묶음은 유지.
- 아브로니아3종은 Abronia 카드와 같은 목차 아래 배치. 개별 ID·관심 목록·크기·가격·사진·인기를 보존했다. 모든 카드가 처음부터 표시되며 더 만나보기/페이지 추가 로딩은 없다.
- 검색/환경/크기/관심 조건을 종별 적용한 뒤 묶는다. 묶음 인기순은 가장 앞선 기존 인기 항목으로 결정한다. 대표 사진에 실제 종 이름을 표시하며 속 전체에 하나의 사육/합사 조건을 부여하지 않는다.
- 기존 catalogNode URL·history 구조로 속을 선택해 새로고침/뒤로가기를 유지한다. 큰 분기 URL과 종·모프 ID를 변경하지 않았다. 전체 목차1080노드.
- 식물의 관엽·덩굴·지피는 식재 역할 구분이므로 같은 속에 서로 다른 역할이 있어도 자동 오류로 보지 않는다.
