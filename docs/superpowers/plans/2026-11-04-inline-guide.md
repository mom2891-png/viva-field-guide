# 승인된 메인 목차·상세 패널 작업

사용자 승인: 목차를 메인 중앙 기본 표시, 분류 열 압축, 오른쪽 사진/상세 40% 이상, 생물 선택 시 팝업 없이 갱신. 모바일은 분류 아래 상세. 데이터 추가·공개 배포 제외.

1. 기존 브라우저 검증에 상시 표시/선택 유지 회귀검사를 먼저 추가하고 실패 확인.
2. index/CSS에 메인 목차와 60:40 탐색·상세 영역, 좁은 분류 열 및 모바일 세로 흐름 구현.
3. catalog-browser/app의 선택·상세·URL 복원을 연결하고 사진/가격/모프/즐겨찾기/출처 재사용.
4. 국소 검사 후 전체 검사1회. 화면 도구 사용 가능 시 데스크톱/390px 확인; 불가 시 미완료 기록.
5. 결과·변경파일·미완료를 HANDOFF에 남김. 업로드·배포는 별도 승인.
