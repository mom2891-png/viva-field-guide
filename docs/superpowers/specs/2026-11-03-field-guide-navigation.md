# 비바 생물도감: 다단 목차와 전체 보강 설계

작성일: 2026-11-03 (Asia/Seoul)

## 사용자 의도

더쥬의 첨부 화면처럼 대분류에서 하위 생물군을 펼치고, 원하는 종까지 단계적으로 찾아가는 목차를 원한다. 도감 수록·정보 보강도 이 목차의 각 분기를 조사 단위로 삼는다. 이번 산출물은 설계와 실행 계획이며 실제 메뉴 변경은 아직 실행하지 않는다.

## 검토한 방식

1. **다단 목차 + 검색·조건 필터 병행 — 채택안.** 이름을 몰라도 분류를 따라가고, 이름을 알면 바로 검색한다. 기존 목록 보기도 유지한다.
2. 검색·태그만 확장. 구현은 작지만 어느 군에 무엇이 있는지 한눈에 보기 어려워 사용자 요구를 충족하지 못한다.
3. 엄격한 생물학적 분류계급만으로 탐색. 정밀 분류에는 유리하나 유통명·친숙한 취미 분류와 달라 원하는 생물을 찾기 어렵다.

따라서 취미에서 이해하기 쉬운 탐색 분류와 상세의 학술 분류를 구별한다. 메뉴 각 단계가 항상 같은 분류계급이라는 뜻은 아니다. 정체가 불확실한 생물을 학술 분류에 억지로 확정하지 않는다.

## 1. 동물 목차

상단 동물 도감을 열면 대분류 → 세부군 → 종/미확정 유통항목을 연속해서 탐색한다. 종 아래에 등록된 모프·패턴·지역형이 있으면 한 단계 더 펼칠 수 있다.

```text
동물 도감
├─ 파충류
│  ├─ 게코
│  │  ├─ 크레스티드게코 → 등록 모프·패턴
│  │  ├─ 레오파드게코 → 등록 모프·패턴
│  │  ├─ 펫테일게코 → 등록 모프·패턴
│  │  ├─ 가고일게코 / 리키에너스게코
│  │  ├─ 데이게코류 → 등록 종
│  │  └─ 기타 게코 → 등록 종
│  ├─ 기타 도마뱀
│  │  ├─ 스킨크류 → 등록 종
│  │  ├─ 카멜레온류 → 등록 종
│  │  ├─ 아가마·드래곤·혼리자드류 → 등록 종
│  │  ├─ 모니터류 → 등록 종
│  │  └─ 그 외 도마뱀 → 등록 종
│  ├─ 뱀
│  │  ├─ 보아·파이톤류 → 등록 종
│  │  └─ 콜루브리드·기타 → 등록 종
│  └─ 거북 → 육지/반수생·수생의 확인된 하위군 → 등록 종
├─ 양서류
│  ├─ 개구리·두꺼비
│  │  ├─ 다트프로그류 → 등록 종·지역형
│  │  ├─ 트리프로그류 → 등록 종
│  │  ├─ 팩맨·혼프로그류 → 등록 종
│  │  └─ 그 외 개구리·두꺼비 → 등록 종
│  └─ 도롱뇽·뉴트 → 등록 종
├─ 절지동물
│  ├─ 등각류 → 속/주요 탐색군 → 등록 종·유통형
│  ├─ 톡토기 → 등록 종·유통형
│  ├─ 노래기 → 등록 종
│  ├─ 게·육지소라게 → 등록 종
│  ├─ 거미·전갈·기타 거미류
│  │  ├─ 점핑스파이더 / 타란튤라 / 전갈
│  │  └─ 그 외 거미류 → 등록 종
│  └─ 곤충
│     ├─ 사마귀 / 대벌레·잎벌레 / 딱정벌레
│     └─ 그 외 곤충 → 등록 종
└─ 연체동물
   └─ 달팽이류 → 등록 종
```

- 위 나열은 구조 예시다. 실제 하위 메뉴는 등록 항목과 확인된 분류 매핑에서 만든다. 등록 종이 없는 분기를 판매처처럼 빈 상품 목록으로 내보내지 않는다.
- 게코도 도마뱀에 포함되는 생물이지만 취미 탐색을 위해 독립 메뉴로 두고 나머지는 ‘기타 도마뱀’이라고 표시해 중복을 피한다.
- 거북의 생활형·트리프로그 같은 항목은 탐색군이지 공식 계급이 아니다. 분류 충돌이 있으면 학술적으로 잘못된 부모에 강제 배치하지 않고 별도 검토한다.
- 파충류뿐 아니라 양서류·곤충·거미·노래기·게·달팽이까지 각 분기를 전수 대조한다. 등각류·톡토기 외 동물군을 완료된 것으로 간주하지 않는다.

## 2. 식물 목차

```text
식물 도감
├─ 관엽·초화류
│  ├─ 베고니아 / 페페로미아 / 피레아 / 피커스 …
│  └─ 속 → 종·유통형 → 등록 품종
├─ 브로멜리아류
│  └─ 네오레겔리아 / 틸란드시아 / 구즈마니아 … → 종·품종
├─ 난초류
│  ├─ 보석란 → 속 → 종·유통형
│  └─ 그 외 착생란·소형 난초 → 속 → 종·유통형
├─ 고사리·석송류
│  └─ 속 → 종·유통형
├─ 이끼류
│  └─ 속 → 종·유통형
├─ 우산이끼류
│  └─ 속 → 종·유통형
└─ 식충식물
   └─ 속 → 종·품종
```

- 덩굴·지피·수변·착생은 서로 겹칠 수 있는 생활형·식재 용도이므로 별도 필터로 제공한다. 예: 피커스는 피커스 목차에 한 번 수록되고 덩굴·벽면 식재에서 다시 찾을 수 있다.
- 난초류 안에서 보석란을 분리해 찾되 난초와 별개의 식물군으로 세지 않는다. 틸란드시아는 브로멜리아류 아래에서 찾을 수 있게 한다.
- 부채괴불이끼·수염이끼류는 고사리 목차에 둔다. 판매명에 ‘이끼’가 들어간다는 이유로 이끼류에 중복 배치하지 않는다.
- 현재 category를 일괄 덮어쓰지 않는다. 탐색용 목차 매핑과 식재 태그를 먼저 도입하고 기존 필터의 의미를 보존하며 전환한다.

## 3. 메뉴·목록·상세의 연결

- 데스크톱: 상단 메뉴의 다단 펼침. 열 선택에 따라 옆 열에 하위 목차가 나온다. 클릭/키보드로 열고 선택할 수 있고 hover는 보조 동작으로만 사용한다. 긴 목록은 열 안에서 스크롤하며 종 이름으로 바로 찾을 수 있다.
- 모바일·터치: 목차 버튼으로 패널을 열고 한 단계씩 탭한다. 상위 제목·뒤로·닫기를 항상 제공한다. 넓은 메뉴를 축소하거나 hover에 의존하지 않는다.
- 모든 분기에 ‘이 분류 전체 보기’를 제공한다. 전체 동물/전체 식물 목록도 바로 열 수 있다. 긴 경로를 반드시 끝까지 눌러야만 종을 볼 수 있게 만들지 않는다.
- 목차 항목 옆 숫자는 하위의 고유 도감 항목 수다. 모프·품종·판매 옵션 수는 별도 표시해 종 수에 합치지 않는다. 종과 미확정 유통형이 섞인 수는 ‘항목’으로 표시한다.
- 경로 표시: `동물 도감 > 파충류 > 게코 > 크레스티드게코`. 각 상위 경로로 돌아가도 선택 분류·스크롤·검색/필터 상태를 복원한다.
- 모프·품종 선택 시 부모 종과 선택 이름을 함께 표시한다. 그 모프 사진이 없으면 일반 종 사진을 해당 모프 사진처럼 표시하지 않는다.
- 이름 검색은 전체를 대상으로 시작하며 국명·학명·이명·유통명·모프·품종을 찾는다. 선택한 분류 안 검색도 명시적으로 제공한다. 결과에는 경로와 항목 유형을 보여준다.
- URL은 안정적인 목차 ID·항목 ID를 사용한다. 새로고침·공유 링크·브라우저 뒤로/앞으로에서 동일 경로가 복원돼야 한다. 한글 표시명 변경으로 링크가 끊기면 안 된다.
- 이전처럼 상세 dialog를 유지할지 독립 경로 화면으로 바꿀지는 작은 구현 설계에서 확정한다. 어느 쪽이든 종 상세 URL·목차 복귀·기존 관심 목록을 보존한다.

## 4. 분류와 별도로 제공할 조건

|조건|예시|규칙|
|---|---|---|
|환경|습식·건조·냉량·환기·반수생|같은 환경이 합사 가능을 뜻하지 않음|
|식재 위치·형태|덩굴·지피·벽면·착생·수변|한 식물에 여러 태그 가능|
|동물 역할|주 사육·정화·먹이|근거가 있을 때만 지정; 역할로 학술 분류를 바꾸지 않음|
|크기·시설|성체 크기·대형 공간·수역 필요|확인된 값만 필터링, 미확인은 별도 표시|
|정보 상태|사진·크기·가격 있음, 종 미확정|수록·관리 조사 완료와 구별|
|관심 목록|브라우저에 저장한 항목|기존 ID와 저장 정보 보존|

‘초보자용’ 점수·종합 적합도·합사 추천을 새로 만들지 않는다. 정확한 관리 근거와 판단 조건을 먼저 채운다.

## 5. 데이터·조사 작업의 연결

목차 노드는 안정적 ID·한국어명·부모 ID·형제 순서·설명과 선택적 탐색 별칭을 가진다. 각 도감 항목에는 대표 목차의 말단 노드를 매핑한다. 필터 태그는 대표 경로와 별개로 저장한다. 실제 과·속 등 학술 정보는 별도 필드로 유지한다.

대표 경로는 하나를 원칙으로 해 전체 수와 분기 합계가 맞도록 한다. ‘정화생물 보기’처럼 여러 경로에서 같은 항목을 찾는 바로가기는 중복 등록이 아니라 공통 ID를 조회하는 필터로 구현한다.

수록되지 않은 후보는 조사 장부에 남긴다. 공개 목차는 지금 찾을 수 있는 항목을 안내하고, 조사 장부는 각 분기에서 아직 채워야 할 후보를 추적한다. ‘기타’에 넣은 항목도 무기한 방치하지 않고 대조 근거와 검토 상태를 남긴다.

## 6. 통합 실행 순서

1. 동물·식물 전체 목차, 분류 매핑 규칙, 종별 필수 정보 양식을 확정한다.
2. 기존523항목을 전부 목차에 배치하고 미배치·중복·잘못된 부모·이명 충돌을 검출한다. 종을 추가하기 전에 현재의 분류 공백을 드러낸다.
3. 목차 UI·경로·검색·모바일·뒤로가기 동작을 한 분기에서 먼저 구현하고 검증한다.
4. 모든 분기에 확장한 뒤, 분기별 국내 판매처 전수 대조와 신규 생물 추가를 진행한다. 빈틈이 큰 군을 먼저 처리하되 동물 전 군을 조사 대상에 포함한다.
5. 신규 추가와 함께 기존 항목의 동정·종별 관리·성체/성숙 크기·사진·가격을 심화한다. 일반적인 분류군 설명만 있으면 관리 완료로 세지 않는다.
6. 분기별 조사 완료·미처리 후보·정보 공백·오류를 검증하고 배치별 기록·커밋·원격 반영·배포 확인으로 마무리한다.

수록 단계별 상세 작업은 2026-11-03-field-guide-completion.md를 따른다. 기존 순서보다 목차 및 전 항목 매핑 작업을 먼저 수행하도록 보완한다.

## 7. 완료·검증 기준

- 기존523항목 모두 유효한 대표 말단 노드가 있고 ID·관심 목록·사진 권리 정보가 보존된다.
- 부모가 없는 노드, 순환 경로, 중복 ID, 무효 경로, 잘못된 분류군 간 배치, 중복 합계를 검사한다.
- 분기별 숫자는 실제 고유 항목 수와 일치하며, 조건 필터 적용 후의 숫자인지 전체 숫자인지 일관되게 표시한다.
- 경로·검색·필터 조합, 미확정 유통명·모프 검색, 전체 보기, 빈 결과 초기화, URL 복원·뒤로가기를 검사한다.
- 마우스와 키보드만으로 목차를 사용할 수 있다. 터치에서 하위 메뉴가 열리고, 390px에서 가로 넘침·메뉴 가림이 없어야 한다.
- 대표 경로 검수: 파충류→게코→크레스티드게코→모프, 양서류→다트프로그→종, 절지동물→등각류→종, 식물→고사리→괴불이끼류→부채괴불이끼, 난초류→보석란→종, 유통명 검색→미확정 상세.
- 데이터 전수 조사와 UI 완료를 구별해 보고한다. 빈 분류가 없다는 이유로 생물 누락이 없다고 선언하지 않는다.
