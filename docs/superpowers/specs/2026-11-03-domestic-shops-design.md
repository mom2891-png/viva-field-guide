# 국내 구매처 모음

## 확정 방향

사용자는 도감 안에 정글플랜트 및 생물 구매 사이트를 모으기를 원하며 국내 사이트만 포함하도록 지정했다. 후속 요청으로 테라리움 완성품·주문제작·자재 판매처와 꿈속의 자연, Firerium, 아이엠모스, 이끼상점, 다채리움, 네이쳐레일을 추가했다. 상단 구매처 탭, 이름순 업체 카드, 취급 품목 필터와 검색을 제공한다. 기존 동물·식물 도감 및 개별 상품 링크는 유지한다. 해외 사이트, 인기 점수, 제휴 순위, 로그인과 결제 기능은 범위 밖이다.

## 화면

- 상단 메뉴는 생물 도감 / 식물 도감 / 구매처. 구매처를 선택하면 별도의 본문을 보여준다.
- 제목은 국내 구매처, 설명은 정글플랜트부터 함께할 생물까지, 국내 판매 사이트를 둘러보세요.
- 검색은 업체명·취급 품목으로 검색한다. 분류는 전체 / 정글플랜트 / 이끼·수초 / 파충류·양서류 / 무척추동물 / 테라리움 완성품·주문제작 / 자재·도구 / DIY 키트. 실제 확인된 업체만 해당 분류에 포함하며 한 업체는 여러 분류에 속할 수 있다. 완성품과 직접 조립하는 키트를 구분한다. 유리 용기·사육장, 바닥재·배수재, 돌·유목, 조명·분무, 핀셋 등은 확인한 자재·도구 품목만 설명에 적는다.
- 카드에는 업체명, 확인된 취급 품목, 홈페이지 링크, 확인일, 도감 연결 항목 수를 표시한다. 연결 항목 수는 같은 종의 여러 상품을 중복 집계하지 않는다. 홈페이지는 HTTPS 및 새 창 안전 속성을 적용한다.
- 도감에 연결된 항목이 있으면 카드에서 관련 항목 목록을 열 수 있다. 동물·식물이 섞인 업체도 한 목록에서 구분하고 각 종 상세로 이동한다. 목록은 기존 상세 dialog를 사용하며 돌아가기는 구매처 목록으로 제공한다.
- 이름순으로 정렬한다. 검색 결과 없음에는 검색 초기화 버튼을 둔다. 모바일 390px에서 메뉴·카드·긴 업체명과 링크의 가로 넘침이 없어야 한다.
- 구매처 확인일은 사이트 접속 확인일이다. 현재 재고·배송 조건은 판매처에서 확인하라는 짧은 안내를 둔다. 연구 원문이나 조사 표는 화면에 노출하지 않는다.

## 구현 경계

dist/shops.json에 고정 ID, 이름, 홈페이지, 분류, 짧은 품목 설명, checkedAt을 저장한다. 기존 purchaseLinks의 shop 이름을 연결 키로 삼아 종 목록을 파생한다. shops.js가 구매처 필터·목록·연결 항목을 담당하며 기존 app.js의 페이지 전환 및 종 상세 진입점에 연결한다. 데이터 경로는 상대 경로와 캐시 버전을 사용한다. 외부 API·새 패키지·빌드는 추가하지 않는다.

사이트 목록 로드 실패는 구매처 화면에서 재시도 안내를 제공하며 기존 두 도감의 로드를 막지 않는다. 업체명이 연결되지 않는 경우 검증에서 실패시켜 오탈자로 인한 연결 누락을 방지한다. 개인 연락처·원문 HTML·조사 캐시는 저장하지 않는다.

## 검증과 완료 기준

기존 npm run check 통과, 업체 ID·홈페이지 중복·HTTPS·분류·확인일 검사, 모든 purchaseLinks 업체 연결 검사, 검색·복수 분류·빈 결과·관련 항목 중복 제거 검사. 브라우저에서 세 탭 왕복, 구매처 검색과 초기화, 관련 항목→상세→구매처 복귀, 외부 링크, 데스크톱/모바일 레이아웃을 확인한다. HANDOFF에 수록 수와 검증 범위를 기록한다. main push 및 공개 배포는 별도 진행 상태로 명확히 보고한다.
