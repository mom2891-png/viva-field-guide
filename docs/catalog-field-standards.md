# 도감 필드 확인 기준

2026-11-03. 승인한 도감 완성 계획의 종별 정보 보강에 적용한다.

|필드|최소 확인 기준|미확인·충돌 처리|
|---|---|---|
|이름·학명|공식 분류 DB 또는 분류 논문과 국내 판매명을 별도로 대조|판매자가 쓴 sp./cf./불완전 학명을 확정 종으로 바꾸지 않는다. 동명·속명 충돌은 상품 연결 보류|
|국내 유통|국내 직접 상품·공개 목록·제공 가격표의 실제 판매명|외국 취급만으로 국내 취급 기록을 만들지 않는다. 판매명만 확인하면 종 일치 미확정 표시|
|크기|성체·성숙 자료에서 수치·단위·측정 부위·최대/범위/하한 구별|판매 당시 규격은 성체 자료로 쓰지 않는다. 측정 부위 차이를 보존하고 상충 시 공란|
|동물 관리|종별 생물 자료 또는 직접 사육자의 전문 기록|일반 등각류·일반 게코 조건을 모든 종에 복사하지 않는다. 경험적 관리 수치를 생리적 한계로 표현하지 않는다|
|식물 관리|종·유통형별 원예·생태 자료|유묘·소형 판매 규격만으로 성숙 크기와 밀폐 적합성을 판단하지 않는다|
|가격|국내 상품에서 가격과 실제 개체 수·규격·옵션을 함께 확인|템플릿의 주문수량1개를 생물1마리로 환산하지 않는다. 단위 미확인 가격은 종 가격에 추가하지 않는다|
|재고|현재 상품의 유효한 재고 표시|본문에 구매와 SOLD OUT이 동시에 노출되면 템플릿 가능성을 기록하고 현재 재고 확정 주장 금지|
|사진|종 일치와 재사용 권한·저작자·원본 URL 확인|상품 이미지를 허가 없이 복사하지 않는다. 특정 모프 사진 대신 일반 종 사진을 사용하면 해당 형태 대표 아님 표시|
|인기|기존 검증 기준에 맞는 별도 자료|신규 발견·가격·검색 결과 수를 인기로 바꾸지 않는다|

출처 URL·확인일·대상 필드와 한계를 조사 장부에 남긴다. 상세 원문·수집 로그는 checkout 밖 연구 폴더에 보관한다. 입력됨과 전수 검증됨은 서로 다른 상태다.

현황 집계: `node scripts/catalog-status.mjs`. 이 출력은 입력 유무를 재현하며, 생물학적 완성도를 계산하지 않는다.
