# 미스터 한 — 도감 UI 편집 기준

사용자 지정 명칭: 미스터 한. 2026-11-05의 직접 지시와 이전 승인에서 확인된 제품 편집 기준이다. 개인 성격·직업·인적 특성을 추정하지 않는다. 공통 작업 규칙은 agent-work-rules.md이며, 최신 사용자 지시가 우선한다.

## 스타일 정의

사진과 핵심 정보가 중심인, 밀도 높고 간결한 실용 도감. 명확한 탐색 구조와 큰 생물 사진을 두고 반복 안내·장식·편집 과정을 기본 화면에서 덜어낸다.

## 확인된 명령의 일관성

|확인된 요구|반영할 기준|
|오른쪽 생물 영역을 크게|좁은 왼쪽 목차 + 넓은 사진·정보 본문|
|사진 자르기 금지|원본 비율과 생물 전체를 보존|
|더보기 없이 탐색|항목은 계속 탐색하되 사진 요청은 실제 가시 영역에 한정|
|누른 상태 유지|선택·검색·필터·목록 위치를 보존|
|중복 경로·복귀 문구 삭제|분류 경로는 상단 한 번, 왼쪽 목차와 브라우저 뒤로가기를 활용|
|항목 수·영어 소제목 등 삭제|사용자의 판단이나 조작에 쓰이지 않는 표시는 기본 화면에서 제외|

|케어시트·자랄 자리의 군더더기 제거|관리·빛·온도·물·식재·주의 등 실질적인 내용 위주. 같은 내용은 한 번|
|AI 같은 UI 제거|낭만적 문구·장식용 카드·과도한 여백·검토 과정 설명을 줄이고 정보 위계와 가독성을 높임|

## 구체적인 편집 규칙

1. 기본 상세: 사진 / 이름·학명 / 짧은 사실표 / 필요한 모프·품종 선택 / 케어시트.
2. 상단 분류 경로가 있으면 상세 안 경로와 분류 나열은 중복하지 않는다.
3. “1개 도감 항목”, “BOTANICAL FIELD GUIDE”, “크기와 참고 가격”, 두 개의 긴 복귀 링크는 제거한다.
4. 크기와 가격은 값에 비해 큰 박스·넓은 빈칸을 만들지 않는다. 판매 단위·측정 부위는 유지한다. 미입력은 `-`, 실제 로딩 실패는 오류로 구분한다.
5. 케어시트는 실질적인 관리 내용을 먼저 표시한다. 자료명·작성자·검토 상태·발행일·긴 적용 범위·추가 확인 목록은 접힌 출처 기록에서 확인할 수 있게 한다.
6. 원문 직접 안내와 편집자의 식재 제안은 구분한다. 식재 제안이라는 짧은 라벨과 방법·주의를 유지하고 긴 위치 선정 이유는 접는다.
7. 이미 케어시트에 있는 배치·관리 설명을 “자랄 자리”로 다시 반복하지 않는다.
8. 종 미확정·유통형 제한·수중과 육상 관리 구분·냉각 등 판단을 바꾸는 주의사항은 남긴다. 모프·품종에 부모 관리가 연결된 사실도 짧게 표시한다.
9. 원본 데이터·출처·사진 저자/권리·동정 한계는 보존한다. 화면 단순화를 이유로 근거 없는 수치나 확정 표현을 만들지 않는다.
10. 장식을 줄인다는 이유로 글씨를 작고 흐리게 만들지 않는다. 내용에 맞는 높이·간격·대비를 확보한다.

## 재사용 프롬프트

> 이 도감 UI를 미스터 한 기준으로 편집해. docs/mister-han-style.md와 공통 작업 규칙을 먼저 읽어. 사진·이름·핵심 사실·케어가 먼저 보이게 하고 중복 경로, 장식용 소제목, 불필요한 항목 수, 긴 복귀 문구, 반복 설명과 과도한 박스를 제거해. 미확인 값은 `-`로 표시해. 출처·사진 권리·유통형/종 미확정·수중/육상 등 중요한 적용 제한은 보존하고 기록은 접어서 분리해. 기존 데이터·사진·탐색·위치 복원·가시 영역 사진 로딩을 보존해. 새 사진이나 수치를 만들어 채우지 마. 로컬 구현·검증과 공개 배포는 구분하고 업로드·배포는 별도 지시를 받아.

## 완료 판정

- 같은 분류 경로·관리 설명이 기본 화면에서 반복되지 않는다.
- 미확인 크기·가격에 “확인 중” 대신 `-`가 나온다.
- 필수 정보 대비 박스·여백·소제목의 면적이 과하지 않다.
- 출처와 사진 권리는 여전히 열람할 수 있고 적용 제한이 왜곡되지 않는다.
- 기존 기능·가시 영역 사진 로딩·실제 화면 검수 상태를 정직하게 보고한다.
