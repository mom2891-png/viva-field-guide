- Hyla cinerea / Litoria caerulea / Litoria infrafrenata의 속 변경 후보는 ASW 검색 색인에 보이나 원문 유지보수·시간초과로 이번 대표 학명 변경에서 제외. 원문 복구 후 종 경계·기존 경로 영향을 확인한다.
